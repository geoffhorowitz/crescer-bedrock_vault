# Mollusk Platform

**Summary**: Mollusk is Bedrock's batch processing platform for post-survey sonar data reprocessing. It complements onboard real-time detection.

**Last updated**: 2026-07-18

---

## Role

The milestone deck describes an operational workflow where the onboard model auto-detects discrete objects per SSS waterfall swath, with later re-runs after navigation post-processing and optional batch processing in Mollusk (source: SOW 1 Milestone 2 Presentation.pptx:11).

Mollusk serves as the offline, higher-fidelity processing step that refines onboard detections once navigation data has been finalized.
