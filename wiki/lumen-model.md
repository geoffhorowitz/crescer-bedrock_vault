# Lumen Model

**Summary**: Lumen is Crescer AI's object detection model line used for Bedrock SSS ATR. It was benchmarked against U-Net (ResNet-50) and YOLOv8 before being adopted as the production direction.

**Last updated**: 2026-07-18

---

## Origin

The milestone deck (Q3 2025) references "Lumen object detection models" as Crescer's chosen architecture for lightweight onboard deployment (source: SOW 1 Milestone 2 Presentation.pptx:25). SOW 2 Milestone 2 references a "retrained Lumen model with UXO-style objects" (source: Bedrock SOW 2.md:19).
