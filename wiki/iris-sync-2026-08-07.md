# Iris Sync - August 7, 2026

**Summary**: The team evaluated Version 4 model performance across 5-fold cross-validation, pivoted from diffusion models to VLM/LLM code-based procedural generation for synthetic UXO objects, established early stopping criteria for K-fold runs, defined a four-bucket reporting framework to convey recall/precision trade-offs, restored copy-paste augmentation into training, and defined Milestone 2 completion deliverables.

**Last updated**: 2026-08-07

---

## Key Highlights & Discussion Points

### Procedural Generation Pivot & VLM Code Generation
- **Diffusion Abandonment**: Shelved diffusion-based object generation for UXO targets because it failed to generate structured target morphology, producing unusable "blobs" (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **VLM Code-Based Procedural Generation**: Pivoted to generating synthetic UXO targets procedurally using VLM/LLM-written code. Categorized target shapes into four geometric classes: circles, ovals, teardrops (water drop), and cylindrical/cone shapes, applying polygon vertex jittering and intensity darkening (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **VLM Input Method Testing**: Agreed to test two VLM input strategies: close-cropped objects (retaining local background context for lighting/shadow alignment) versus background-stripped/transparent objects (isolating object morphology) (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **100k Embedding Cluster App**: Pratyaksh generated ~100,000 synthetic images and clustered them via embedding maps (UMAP/t-SNE); building an interactive side-by-side app to compare real versus synthetic samples (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).

### Model V4 K-Fold Benchmarks & Training Policies
- **V4 Base Overfitting vs. Augmented Recall**: Base V4 without augmentations suffered from severe overfitting due to strict false-negative penalty weights. Incorporating standard image-space augmentations (color/noise) resolved overfitting, yielding ~90% recall with ~20–50% precision (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **Zero-F1 Early Stopping Criteria**: Established policy to terminate K-fold training runs early if the F1 score drops to 0, indicating learning failure (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **Restoration of Cut-and-Paste Training Data**: Identified that earlier evaluation issues with artificial copy-paste data stemmed from missing ground truth annotations on base images. Agreed to train a dedicated model incorporating corrected cut-and-paste data, as copy-paste augmentation had been omitted in V4 (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **Model Deferment Policy**: Agreed to defer sharing the best-performing model with external stakeholders until the next milestone to demonstrate clear step-by-step progress (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).

### Four-Bucket Matrix Reporting Framework
- **Hierarchical Classification Strategy**: Established a four-bucket reporting framework for model performance:
  1. UXO-like objects (True UXO, AOI Small Black)
  2. Non-UXO-like objects (AOI Big, Black Patch / windmill support structures)
  3. Background noise
  4. True UXO vs. UXO-like object breakdown (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **Recall Priority & Precision Selectivity**: Confirmed client priority is high recall on true UXO targets, while maintaining enough selectivity on non-UXO background objects to prevent manual verification overload (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).

### Milestone Completion & Future Scope
- **Milestone 2 Completion Deliverables**: Finalized criteria: (1) complete 5-fold cross-validation metrics, (2) train model incorporating cut-and-paste data, and (3) validate performance on the Treasure Island dataset (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **Milestone 3 / MAG Data Resumption**: Resuming magnetometer (MAG) data analysis next week, focusing on location-buffer target detection (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
- **Swedish Rockan Mine Reference**: Bridget shared documentation regarding a potential Swedish-made Rockan mine-like object (MLO) for target cataloging (source: Iris Sync - 2026_08_07 12_16 EDT - Notes by Gemini.md).
