# Iris Sync - July 31, 2026

**Summary**: The team reviewed sonar object categorization protocols, addressed V4 metric/overlap bugs, paused K-fold training due to base ground truth data issues, and pivoted to pixel cropping and LoRA latent diffusion models for synthetic data generation and pruning.

**Last updated**: 2026-07-31

---

## Key Highlights & Discussion Points

### Data Categorization & Unique Object Grouping
- Established a file documentation protocol to categorize sonar scans into XTF and DRN groups (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).
- Each group represents a unique physical object, accounting for duplicate observations across multiple sonar scan passes (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).

### Model Training & Performance Baseline
- The July 27 **V4 model** remains the current performance baseline (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).
- Identified and fixed metric calculation bugs in V4 concerning annotation handling and overlap processing for overlaps below 0.1 IoU (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).
- Paused K-fold model training mid-process after failing to reach 50% IoU due to underlying base ground truth annotation markings that require resolution (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).

### Synthetic Data Generation & Augmentation Strategy
- **Pixel Crop Pivot**: Pivoted from manipulating raw XTF sensor values to using pixel crops for object manipulation, finding pixel crops sufficient given high physics accuracy for shadows is not required for project goals (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).
- **LoRA Object Generation**: Training a LoRA model on 144 object crop examples for novel synthetic object generation (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).
- **Latent Diffusion & Pruning**: Evaluated latent diffusion models for background generation and proposed computing latent space distance metrics (such as FID) to prune near-duplicate synthetic images and maintain dataset diversity (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).

### Empirical Mode Decomposition (EMD) Tooling
- Work continues on Empirical Mode Decomposition (EMD). The team planned an interactive EMD application where users can select source images, adjust parameters, and inspect generated intrinsic mode functions (IMFs) (source: Iris Sync - 2026_07_31 12_26 EDT - Notes by Gemini.md).
