# Iris Sync - August 12, 2026

**Summary**: The team diagnosed and initiated fixes for a crop-level data leakage bug in the 5-fold cross-validation pipeline, uncovered a critical silent bug in the `dual_transform` augmentation pipeline that had caused custom transforms (including Poisson copy-paste) to be bypassed during earlier training, reviewed strong V4 AUG + Copy-and-Paste benchmark results (92% F1 on a merged UXO/AOI small black metaclass on the verified 80/20 split), examined procedural synthetic training metrics (50–60% recall on UXO classes) and 3D floating object artifacts, and aligned on the end-of-August Milestone 2 Jetson deployment target.

**Last updated**: 2026-08-12

## Key Highlights & Discussion Points

### K-Fold Data Leakage Root Cause & Resolution
- **Crop-Level Partitioning Issue**: Investigation into false positive metrics identified data leakage during K-fold cross-validation splitting. The issue occurred at the image crop level where specific files were repeated across folds, resulting in instances where an image had annotations in one fold but lacked them in another, creating training and validation set overlap (estimated at ~14% file duplication, subject to exact verification) (source: Iris Sync - 2026_08_12).
- **24-Hour Fix & Retraining Plan**: Sachin estimated 24 hours to resolve the crop-level partitioning logic, with Pratyaksh and Ratul assigned to assist. The team plans to retrain the top two model configurations from each fold and generate updated confusion matrices within 48 hours (source: Iris Sync - 2026_08_12).

### Discovery of Silent Augmentation Bug (`dual_transform` / `always_apply`)
- **Root Cause in `augmentation.py`**: Pratyaksh uncovered a silent bug in the custom augmentation implementation subclassing `dual_transform`. The constructor invoked `super().__init__(always_apply, p)`. In modern versions of the library accepting `**kwargs`, passing `always_apply` (a boolean) positioned it as the `p` (probability) parameter (source: Iris Sync - 2026_08_12).
- **Impact on Training**: When unit-tested with `always_apply=True`, `p` was set to `1.0` (always executing). In the training pipeline where `p` was set to `0.5`, `0.7`, or `0.9`, custom hand-written augmentations were completely ignored (source: Iris Sync - 2026_08_12).
- **Resolution of Historical Anomalies**: This finding explains prior counterintuitive results where perspective transforms appeared to outperform Poisson copy-paste—Poisson copy-paste was never actually executed in earlier training runs (source: Iris Sync - 2026_08_12).

### V4 Model Performance on Verified 80/20 Split & Ground Truth Mining
- **High Benchmark Performance**: Sachin completed training and initial evaluation of Version 4 with image augmentations and copy-and-paste on the clean, verified single 80/20 train/validation split. Merging `UXO` and `AOI small black` into a single metaclass produced an **F1 score of 92% (Precision ~94%, high recall)**, with an F1 score of 74% for pure isolated UXO (source: Iris Sync - 2026_08_12).
- **Ground Truth Remediation**: Sachin integrated false-positive review findings into the master annotations, adding ~80 UXO-like detections into the `AOI small black` ground truth training set to improve annotation consistency (source: Iris Sync - 2026_08_12).
- **HTML Summary Deliverable**: Geoff directed Sachin to independently verify the predictions visually and document the confusion matrices and imagery in an HTML summary report within 24 hours (source: Iris Sync - 2026_08_12).

### Procedural Synthetic Generation & 3D Artifacts
- **Synthetic-Only Model Recall**: Pratyaksh trained a model exclusively on procedurally generated synthetic labels, achieving **50%–60% recall on UXO classes** (Class 6: actual UXO, Class 3: UXO-like), though performance was low on larger AOI support classes due to the absence of synthetic support data (source: Iris Sync - 2026_08_12).
- **3D Floating Object Artifact**: Ratul reported that 3D synthetic objects appear to "float" above the seabed due to a perceived 2-pixel gap between objects and shadows. Adjusting the pixel offset to zero did not resolve it; investigations continue into alpha blending and Fourier series outline representations. Parameter ranges for "fit/pit" and "bulge" are available in the shared configuration file (source: Iris Sync - 2026_08_12).
- **Water-Line & Padding Masking**: Pratyaksh updated color-based augmentations (e.g., image inversion) to mask out empty black space and padding so only valid sonar data is altered, with plans to test similar masking for noise transforms (Gaussian blur) (source: Iris Sync - 2026_08_12).

### Milestone 2 Scope, Delivery Timeline & Hardware Deployment
- **Performance Criteria**: Geoff clarified that Milestone 2 requires demonstrating measurable performance improvements over the previous milestone delivery rather than isolating synthetic data gains in the abstract (source: Iris Sync - 2026_08_12).
- **Timeline**: Hard stop deadline set for the end of August 2026, inclusive of documentation, report generation, and onboard Jetson execution (source: Iris Sync - 2026_08_12).
- **Jetson Deployment Architecture**: The inference pipeline will execute directly on the Jetson device, while the Streamlit user interface will be hosted locally/on the Wally server. Geoff and Sachin scheduled a weekend review to verify deployment scripts (source: Iris Sync - 2026_08_12).
- **Data Format Standardization**: Standardized image and mask tile split dimensions to 128, 256, and 512 pixels for XTF data preparation (source: Iris Sync - 2026_08_12).

### Client Engagement & AI Workflow Insights
- **Real vs. Synthetic Image Game**: Hemanth proposed developing a lightweight interactive application for Bedrock (e.g., Bridget) challenging users to identify real vs. synthetically generated side-scan sonar images to demonstrate synthetic capabilities (source: Iris Sync - 2026_08_12).
- **AI-Assisted Code Verification**: The team discussed strategies to prevent silent AI coding bugs, including independent multi-agent code reviews (e.g., using Claude Code, Codex, Antigravity), Ratul's knowledge graph/mind-map contextual scoping workflow, T3 Code for remote server development, and maintaining rigorous critical thinking when experimental outcomes defy technical expectations (source: Iris Sync - 2026_08_12).
